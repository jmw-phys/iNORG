# Citing iNORG

When publishing calculations with iNORG, cite the iNORG code paper:

Jia-Ming Wang, Yi-Heng Tian, Yin Chen, Ru Zheng, Rong-Qiang He, Zhong-Yi Lu, **iNORG: An open-source quantum impurity solver package based on the natural orbitals renormalization group**, [arXiv:2607.13993 (2026)](https://arxiv.org/abs/2607.13993).

Also cite the method paper listed in the repository README:

Jia-Ming Wang, *et al.*, **Ab initio dynamical mean-field theory with natural orbitals renormalization group impurity solver: Formalism and applications**, *npj Computational Materials* **11**, 86 (2025). [Publisher article](https://www.nature.com/articles/s41524-025-01586-6).

Record the iNORG version or source revision and the input settings used for your results. This helps readers reproduce the bath discretization, occupation constraints, and frequency mesh. Use the publisher's citation export if you need a complete author list or BibTeX entry.
